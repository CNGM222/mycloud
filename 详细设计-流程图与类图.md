# 详细设计-流程图与类图

## 1. 文档说明

本文档在《详细设计.md》的基础上，将系统设计逐个落实为流程图和类图。图示使用 Mermaid 语法，可在支持 Mermaid 的 Markdown 工具中直接渲染。

覆盖范围：

- 系统总体结构。
- 后端核心模块。
- 数据库实体关系和本地文件存储关系。
- Vue 3 网页端。
- Windows Electron 客户端。
- Android Kotlin 客户端。

## 4. 文件管理模块

### 4.1 文件列表流程图

```mermaid
flowchart TD
    A[客户端请求文件列表] --> B[JWT 认证]
    B --> C{parentId 是否为空}
    C -->|是| D[查询根目录文件]
    C -->|否| E[校验 parentId 属于当前用户且为 folder]
    E --> F{校验是否通过}
    F -->|否| E1[返回权限不足或目录不存在]
    F -->|是| G[分页查询 files]
    D --> G
    G --> H[返回文件列表]
```

### 4.2 文件上传流程图

```mermaid
flowchart TD
    A[客户端选择文件] --> B[multipart 上传]
    B --> C[JWT 认证]
    C --> D[校验目标目录权限]
    D --> E{文件名是否合法}
    E -->|否| E1[返回参数错误]
    E -->|是| F[处理重名策略]
    F --> G{剩余容量是否足够}
    G -->|否| E2[返回容量不足]
    G -->|是| H[创建 running 任务]
    H --> I[流式写入 .tmp 并计算大小和 MD5]
    I --> J{文件与磁盘校验是否通过}
    J -->|否| E3[删除临时文件并标记任务 failed]
    J -->|是| K[原子移动到 objects 正式路径]
    K --> L[开启数据库事务并锁定用户容量]
    L --> M[插入 files 元数据和 storage_key]
    M --> N[更新 users.used_capacity]
    N --> O[任务改为 success 并写入日志]
    O --> P[提交事务并返回文件信息]
    L --> Q{数据库步骤是否失败}
    Q -->|是| R[回滚事务并补偿删除正式文件]
    R --> S[清理失败则记录告警并交由巡检]
```

### 4.3 文件下载流程图

```mermaid
flowchart TD
    A[客户端请求下载] --> B[JWT 认证]
    B --> C[查询 files]
    C --> D{文件是否存在且归属当前用户}
    D -->|否| E1[返回资源不存在或权限不足]
    D -->|是| E{类型是否 file}
    E -->|否| E2[返回参数错误]
    E -->|是| F[创建下载任务]
    F --> G[设置 HTTP 下载响应头]
    G --> H{storage_status 是否 active}
    H -->|否| E3[返回存储异常]
    H -->|是| I[安全解析 storage_key]
    I --> J[Files.newInputStream 读取本地文件]
    J --> K[分块写入响应输出流]
    K --> L[任务改为 success]
    L --> M[写入 download 日志]
```

### 4.7 删除流程图

```mermaid
flowchart TD
    A[提交删除文件 ID] --> B[JWT 认证]
    B --> C[查询目标节点]
    C --> D{是否属于当前用户}
    D -->|否| E1[返回权限不足]
    D -->|是| E{是否文件夹}
    E -->|是| F[递归查询所有子节点]
    E -->|否| G[仅处理当前文件]
    F --> H[统计释放容量]
    G --> H
    H --> I[短事务标记文件为 deleting]
    I --> J[物理文件原子移动到 .trash 隔离目录]
    J --> K[开启数据库事务]
    K --> L[子节点优先删除 files 元数据]
    L --> M[更新 users.used_capacity]
    M --> N[写入 delete 日志]
    N --> O{事务是否提交成功}
    O -->|是| P[异步清理隔离目录]
    O -->|否| Q[回滚并恢复物理文件和 active 状态]
    P --> R[失败时交由巡检重试]
    Q --> R
```
